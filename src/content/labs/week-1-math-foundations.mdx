## Conceptual Background

Spatial transformations form the mathematical backbone of spatial AI, visual odometry, and robotics.

### 2D Rotation Matrices

A point **p** = [x, y]ᵀ rotated counter-clockwise by angle θ around the origin is transformed via:

```
R(θ) = [ cos(θ)  -sin(θ) ]
       [ sin(θ)   cos(θ) ]
```

### Homogeneous Coordinates & SE(3) Transformations

To combine rotation **R** ∈ SO(3) and translation **t** ∈ ℝ³ into a single matrix multiplication, we use Special Euclidean group SE(3) representations in 4×4 homogeneous matrices:

```
T = [  R   t ]
    [ 01×3 1 ]
```

<Tip>
Using homogeneous transformations allows pose compounding simply by multiplying matrices: T_A_to_C = T_A_to_B × T_B_to_C.
</Tip>

## Starter Code: Rotation Matrices & SE(3) Transformations

Below is the initial Python starter template. Implement the function placeholders using `numpy`.

```python
import numpy as np

def rotation_matrix_2d(theta: float) -> np.ndarray:
    """
    Computes a 2D rotation matrix for a given angle in radians.

    Args:
        theta: Angle in radians.

    Returns:
        2x2 numpy array representing SO(2) rotation matrix.
    """
    c, s = np.cos(theta), np.sin(theta)
    return np.array([
        [c, -s],
        [s,  c]
    ], dtype=np.float64)


def make_se3_transform(R: np.ndarray, t: np.ndarray) -> np.ndarray:
    """
    Constructs a 4x4 SE(3) homogeneous transformation matrix.

    Args:
        R: 3x3 rotation matrix
        t: 3x1 or 3-element translation vector

    Returns:
        4x4 SE(3) homogeneous matrix.
    """
    T = np.eye(4, dtype=np.float64)
    T[:3, :3] = R
    T[:3, 3] = np.asarray(t).flatten()
    return T


def transform_points(T: np.ndarray, points: np.ndarray) -> np.ndarray:
    """
    Applies an SE(3) transformation to an array of 3D points.

    Args:
        T: 4x4 homogeneous transform
        points: (N, 3) array of 3D points

    Returns:
        (N, 3) array of transformed 3D points
    """
    num_points = points.shape[0]
    # Convert to homogeneous coordinates (N, 4)
    ones = np.ones((num_points, 1), dtype=points.dtype)
    points_h = np.hstack([points, ones])

    # Apply transformation: (T @ points_h.T).T
    transformed_h = (T @ points_h.T).T
    return transformed_h[:, :3]


if __name__ == "__main__":
    R_demo = rotation_matrix_2d(np.pi / 4)
    print("2D Rotation (45 deg):\n", R_demo)
```

<Warning title="Numerical Precision Notice">
Always verify that rotation matrices remain orthogonal (Rᵀ R = I) with det(R) = 1. In long pose-chaining pipelines, floating-point drift can corrupt rotation matrices. Perform periodic orthogonalization using SVD or QR decomposition.
</Warning>
