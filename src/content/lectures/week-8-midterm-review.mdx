# Lecture 8: Midterm Review & Project Checkpoint

> **The hook:** Half a course of tools becomes one pipeline. Today the question is not "can you run each stage" but "do you know which stage broke".

## One Pipeline

Calibrate → undistort → rectify → detect and describe → match → ratio test → RANSAC → pose or depth → validity checks. Every stage assumes the previous one is correct.

---

## Failure Signatures

Wrong intrinsics: depth biased by a constant factor. Missing undistortion: straight lines bow near the image edges and stereo matches fail there. Skipped RANSAC: pose jumps between frames. Bad rectification: disparity map full of holes.

---

## Review Problems

Each midterm problem asks you to (1) name the stage, (2) state its precondition, and (3) give a numerical check that proves the stage worked. Practice that three-part answer on every week of the course.

```python
def coverage(depth, zmin=0.2, zmax=20.0):
    valid = np.isfinite(depth) & (depth > zmin) & (depth < zmax)
    return valid.mean()
```

<Warning title="Common Misconception">

Matching on raw, undistorted frames or estimating the essential matrix on all matches. Calibration gates geometry; RANSAC gates pose.

</Warning>
