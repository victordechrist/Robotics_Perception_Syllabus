## NeRF

A NeRF is a network that maps a 3D point and view direction to density and color. Rendering samples points along each ray, queries the network, and alpha-composites the results.

```python
t = np.linspace(near, far, n_samples)
pts = o + t[:, None] * d
sigma, rgb = nerf(pts, d)
delta = np.diff(t, append=far)
alpha = 1 - np.exp(-sigma * delta)
T = np.cumprod(np.r_[1.0, 1 - alpha[:-1]])
color = (T * alpha)[:, None] * rgb
pixel = color.sum(0)
```

## Learned Descriptors

Networks such as SuperPoint produce descriptors that are matched by cosine similarity — L2-normalize them first, or magnitude dominates the comparison.

---

## Fallback Policies

Prefer the learned matcher when its inlier count clears a threshold; otherwise fall back to ORB + RANSAC. Inlier count is a cheap, honest confidence signal.

---

## Performance

Profile before optimizing. Report p50 and p95 latency per stage; the controller feels the tail, not the mean.

<Warning title="Common Misconception">

Trusting a learned matcher unconditionally, or reporting mean latency only. Gate learned outputs; report percentiles.

</Warning>
