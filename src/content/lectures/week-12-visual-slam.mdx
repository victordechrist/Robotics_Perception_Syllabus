# Lecture 12: Visual SLAM Foundations

> **The hook:** To localize you need a map; to map you need to know where you are. SLAM solves both at once — and loop closure is the moment it pays off.

<Note title="What We Cover">

- The SLAM problem: joint pose and map estimation
- Front end: tracking and keyframe selection
- Loop closure: place recognition plus geometric verification
- Back end: pose-graph optimization
- g2o and GTSAM in practice

</Note>

---

## Front End

Track features frame to frame, estimate relative motion, and promote a new keyframe only when parallax is large enough. Keyframing every frame bloats the graph with nearly identical constraints.

---

## Loop Closure

Place recognition (bag-of-words) finds candidate revisits. Geometric verification — RANSAC on matched features — confirms them. A single false loop edge can fold the whole map.

---

## Pose-Graph Optimization

Nodes are keyframe poses; edges are relative-pose constraints from odometry and loop closures. Optimizing the full graph redistributes accumulated drift over every pose.

```python
import gtsam

graph = gtsam.NonlinearFactorGraph()
graph.add(gtsam.PriorFactorPose2(0, gtsam.Pose2(0, 0, 0), prior_noise))
for i, (dx, dy, dth) in enumerate(odometry):
    graph.add(gtsam.BetweenFactorPose2(i, i + 1, gtsam.Pose2(dx, dy, dth), odom_noise))
graph.add(gtsam.BetweenFactorPose2(n - 1, 0, loop_pose, loop_noise))
result = gtsam.LevenbergMarquardtOptimizer(graph, initial).optimize()
```

<Warning title="Common Misconception">

Adding unverified loop edges, or optimizing frame by frame. Verify before closing; optimize globally.

</Warning>
