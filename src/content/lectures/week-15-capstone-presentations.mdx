## Fresh, Reproducible Runs

Every number in your report comes from a clean replay of the dataset through the current pipeline, with fixed seeds. Cached trajectories hide regressions.

---

## Align, Then Measure

Visual odometry estimates live in an arbitrary frame (and, for monocular, an arbitrary scale). Align to ground truth with Umeyama first, then compute ATE (global consistency) and RPE (local drift).

```python
est_aligned = umeyama_align(est, gt, with_scale=True)
ate = np.sqrt(np.mean(np.sum((est_aligned - gt)**2, axis=1)))
rpe = relative_pose_error(est_aligned, gt, delta=1)
```

## Latency

Report p50 and p95 per stage and end to end, measured on the target hardware.

```python
p50, p95 = np.percentile(latencies_ms, [50, 95])
```

<Warning title="Common Misconception">

Computing ATE without alignment, re-using cached outputs, or reporting only mean latency.

</Warning>
