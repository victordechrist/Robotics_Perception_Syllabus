## Covariance Is Structure

A covariance matrix encodes not just how noisy each axis is, but how errors move together. Off-diagonal terms are information: throwing them away makes the model confidently wrong.

```python
L = np.linalg.cholesky(Sigma)
z = np.random.randn(2, N)
noise = L @ z
print(np.cov(noise))  # close to Sigma
```

## Propagating Uncertainty

Linearize the model at the current estimate with Jacobian `F`, then `Sigma_new = F @ Sigma @ F.T + Q`. This is first-order — when the model curves strongly over the uncertainty region, the estimate breaks, and Monte Carlo sampling is the check.

```python
F = jacobian_f(x)
Sigma_new = F @ Sigma @ F.T + Q
```

## Confidence Ellipses

Eigendecompose the 2x2 position covariance: eigenvectors give orientation, `sqrt(eigenvalue * 5.991)` gives the 95% semi-axes for two degrees of freedom.

```python
vals, vecs = np.linalg.eigh(Sigma_xy)
radii = np.sqrt(vals * 5.991)
```

## IMU and Odometry

Gyro and accelerometer noise is white noise plus a slowly drifting bias. Wheel odometry error grows with distance traveled and slip. Both are dead-reckoning sensors: uncertainty only grows until a measurement corrects it — the subject of next week.

<Warning title="Common Misconception">

Scaling each axis by its standard deviation (losing correlation), multiplying covariances elementwise, or using variance instead of standard deviation for ellipse radii.

</Warning>
