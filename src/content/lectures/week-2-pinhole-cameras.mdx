# Lecture 2: Pinhole Cameras & Projective Geometry

> **The hook:** A camera is a function from 3D to 2D that throws away exactly one number — depth. This week you learn which one, and why you can never get it back from a single image.

- Radial and tangential lens distortion

</Note>

## The Pinhole Model

A pinhole camera maps a camera-frame point `(X, Y, Z)` to the normalized image plane by dividing by depth: `x = X / Z`, `y = Y / Z`. Everything that lies on the same ray through the optical center lands on the same pixel — that is the scale ambiguity every monocular method has to fight.

```python
import numpy as np

def project_normalized(P_cam: np.ndarray) -> np.ndarray:
    """Perspective divide: camera-frame (N,3) -> normalized (N,2)."""
    return P_cam[:, :2] / P_cam[:, 2:3]
```

---

## Intrinsics: From Meters to Pixels

The intrinsic matrix `K` maps normalized coordinates to pixels. `fx`, `fy` are focal lengths in pixels, `(cx, cy)` is the principal point — where the optical axis pierces the sensor, which is rarely the exact image center.

```python
K = np.array([
    [fx, 0., cx],
    [0., fy, cy],
    [0., 0., 1.],
])

uv_h = (K @ np.c_[xy_norm, np.ones(len(xy_norm))].T).T
uv = uv_h[:, :2]
```

---

## Extrinsics: Where Is the Camera?

Before projecting, world points must be expressed in the camera frame: `P_cam = R @ P_world + t`. The pair `[R | t]` is the camera pose (world-to-camera). Composed with `K`, it gives the 3x4 projection matrix `P = K [R | t]`.

---

## Lens Distortion

Real lenses bend straight lines. The Brown-Conrady model applies radial terms `k1, k2, k3` and tangential terms `p1, p2` to **normalized** coordinates — before `K`. Applying distortion in pixel space scales the coefficients by the focal length and silently breaks the model.

```python
r2 = x**2 + y**2
radial = 1 + k1*r2 + k2*r2**2 + k3*r2**3
x_d = x*radial + 2*p1*x*y + p2*(r2 + 2*x**2)
y_d = y*radial + p1*(r2 + 2*y**2) + 2*p2*x*y
```

<Warning title="Common Misconception">

Multiplying by `K` before dividing by `Z`, or distorting in pixel coordinates. The order is fixed: world → camera frame → divide by depth → distort → multiply by `K`.

</Warning>
